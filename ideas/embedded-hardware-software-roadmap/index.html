嵌入式软硬件发展路线

2026.11.15

围绕电路设计、4–8 层 PCB Layout、测试，以及 STM32 和 Linux，逐步建立完整的开发能力。

把嵌入式作为长期发展方向，硬件和软件两条线并行推进。目标是逐步具备从需求分析、电路与 PCB 设计、样板测试，到固件开发和 Linux 适配的完整开发能力。

嵌入式硬件：电路设计从需求拆解、器件选型做起，掌握电源、时钟、复位、接口和保护电路的原理图设计，再逐步学习信号完整性、电源完整性与电磁兼容。PCB Layout 重点练习器件布局、叠层规划和走线，以 4–8 层板及 RK3568 板级设计为实践目标。测试方面建立上电前检查、分阶段上电、关键电压与时钟测量、接口验证和问题记录的习惯。

嵌入式软件：先以 STM32 等单片机为基础，练习 C/C++、常用外设、通信协议、驱动开发和调试，再逐步接触实时操作系统。Linux 方向学习交叉编译、系统构建、设备树、驱动和用户空间应用，并结合实际板卡进行软硬件联调。

推进方式：先完成能独立设计、制作和调试的小项目，再逐步挑战 4–8 层 PCB 与 RK3568 相关项目。每个项目都留下设计依据、测试结果和问题复盘。

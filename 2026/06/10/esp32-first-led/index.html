记录 ESP32 开发环境搭建与第一个 GPIO 点灯程序。

一、开发环境

ESP32 的开发方式很多，最轻量的是用 Arduino 框架。安装步骤如下：

  1. 下载并安装 Arduino IDE；
  2. 在「首选项 → 附加开发板管理器网址」中加入 ESP32 的 JSON 地址；
  3. 在开发板管理器中搜索 ESP32 并安装。

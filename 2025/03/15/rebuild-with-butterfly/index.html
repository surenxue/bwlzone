用静态博客主题重构我的个人站点
发表于2025-03-15|技术前端

一、为什么重构

原来的站点是一个单页 Vue 应用，虽然功能多（设置面板、云端同步、音乐、壁纸）， 但对我来说维护成本高、内容也不像「博客」。

二、怎么做

我直接复用了 Butterfly 主题的 css/、js/ 与图片资源， 用一份 Python 小脚本生成各页面（首页、文章、归档、分类、标签、关于、友链）， 保持零构建——改完推到 GitHub Pages 即可上线。

把这里的占位文章替换成真实笔记，并持续更新。
